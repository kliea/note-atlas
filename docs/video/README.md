# Note Atlas explainer video

[![Note Atlas explainer (3:55)](note-atlas-explainer-poster.jpg)](note-atlas-explainer.mp4)

A 3:55 academic explainer of Note Atlas: why local RAG, the three modules (Boards, Files, Research Track), how an uploaded paper is processed, the Claude MCP bridge, and how the design keeps answers accurate.

| File | What it is |
| --- | --- |
| `note-atlas-explainer.mp4` | 1920×1080, 30 fps, H.264 + AAC |
| `note-atlas-explainer.srt` | English captions, generated from the script |
| `note-atlas-explainer-poster.jpg` | 1280×720 thumbnail |
| `src/` | Everything needed to rebuild the video |

Everything on screen is drawn in code, and the narration and music are generated too, so the build needs no stock footage, recordings or licensed audio.

## What is illustrative

The pipeline stages, model names, thresholds and tool names match the code in this repo (`backend/app/research_jobs.py`, `paper_extract.py`, `paper_parents.py`, `rag.py`, `files/`, `mcp_server.py`). The example data on screen is invented for illustration and isn't output from a real run: similarity scores, file names, chunk counts, the three example limitations, and Paper A–D.

## Rebuild it

Requirements: Python 3.11+, `ffmpeg`, and the Inter and DejaVu Sans Mono fonts.

```bash
cd docs/video/src
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
# fonts somewhere other than /usr/share/fonts?
#   export INTER_DIR=/path/to/inter  MONO_FONT=/path/to/DejaVuSansMono.ttf
JOBS=2 ./build.sh
```

`build.sh` writes `../note-atlas-explainer.mp4` and `../note-atlas-explainer.srt`. Intermediate files go to `src/build/`, which git ignores. On first run it downloads the Kokoro voice model (about 350 MB) from GitHub. On a laptop a full build takes roughly 10–20 minutes, depending on `JOBS`.

## How it is made

| Step | File | Notes |
| --- | --- | --- |
| Script | `src/lines.py` | One narration line per scene, 20 scenes |
| Voice | `src/tts.py` | [Kokoro](https://github.com/thewh1teagle/kokoro-onnx) 82M via ONNX, voice `bm_george` (British English), speed 1.06 |
| Visuals | `src/render_base.py`, `render_modules.py`, `render_full.py` | 2D motion graphics drawn with [skia-python](https://github.com/kyamagu/skia-python), streamed to ffmpeg one scene per file |
| Sync | `render_full.cue()` | Each animation is keyed to the position of a phrase in its narration line, so editing the script re-times the visuals |
| Music | `src/music.py` | Original ambient piano and pad, synthesised with numpy, so there are no samples or licences |
| Mix | `src/mix.py` | Narration on the scene grid. The music is ducked to −21 dB under speech and −14 dB in pauses |
| Captions | `src/captions.py` | SRT cues split from the script, timed by character share |

Palette: dark blue `#0A1628`, white `#F4F7FB`, teal `#2EC4B6`.

To change the wording, edit `src/lines.py` and rerun `build.sh`. Scene timings follow the new narration automatically. If you remove a phrase that a scene's `cue()` call looks for, the build stops with an assertion naming the scene and the phrase.
